Publish, version, share

A drawing that lives beside the page as a plain .excalidraw file. Read mode fits it to the frame, pan and zoom included; Edit opens the editor, Save writes the scene to the artifact store and Download writes the file back out.

What Save does

Save puts the scene in the artifact store at _data/sketch-main, which is the one place a page may write. That store needs a signed in viewer, so a public visitor is told to sign in, a folder that has not been published yet is told that saving starts once it is, and a scene over 64 KiB is told to use Download instead.

Download writes drawing.excalidraw with the palette the drawing was authored in, whatever mode you were in, so the file can be committed and published as a new version. Publish that file and the sketch in the store stops being newer than it.

With JavaScript off

The frame is empty and the drawing is still a file: open drawing.excalidraw in the Excalidraw editor, or read it as JSON, which is what it is.
